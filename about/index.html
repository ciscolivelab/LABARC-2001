    About The Lab

    Learning Objectives

    By the end of this lab, you will be able to:

    • Deploy an OSPF policy using localized control policies

    • Deploy a QoS policy using localized data policies

    • Implement a Hub-and-Spoke topology using centralized control policies

    • Configure Application-Aware Routing (AAR) using centralized data policies

    Catalyst SD-WAN Manager

    Cisco Catalyst SD-WAN Manager offers a centralized platform for configuring, managing, operating, and monitoring the entire SD-WAN fabric. All lab tasks will be performed using Catalyst SD-WAN Manager.

    Localized Policy Oveview

    Localized policies are configured and enforced directly on SD-WAN Edge devices. There are two types of localized policies:

    • Localized Control Policy

    • Localized Data Policy

    In this lab, you will configure an OSPF localized control policy and a QoS localized data policy using Catalyst SD-WAN Manager.

    Centralized Policy Overview

    Centralized policies are applied across the entire SD-WAN fabric and are configured on SD-WAN controllers. Depending on the type of policy, enforcement can occur either on the controllers or on SD-WAN Edge devices. There are two types of centralized policies:

    • Centralized Control Policy

    • Centralized Data Policy

    In this lab, you will configure a Hub-and-Spoke topology using a centralized control policy and deploy Application-Aware Routing (AAR) using a centralized data policy—both via Catalyst SD-WAN Manager.
